This project was developed during the Web Technology course as part of my 3rd semester studies. 
The goal of the project was to apply web development principles and build a scalable, containerized application with MCV architecture.

The idea was a small site where Organizers create events and Attendees see events.
The problem I wanted to address was the difficulty people often have when trying to
organise or participate in events. Attendees usually need an easy way to browse events,
see available seats, and book them, while organisers need a simple interface to create
and manage events. Without a dedicated web solution.

### Tech Stack:
Backend: Laravel 
Frontend: JavaScript, HTML, and CSS3
Database: MySQL 
Containerization: Docker & Docker Compose

### Why this stack?
Laravel: Provides a robust MVC architecture and powerful ORM (Eloquent).
MySQL: A reliable relational database for structured data.
Docker: Used for containerizing the server, database, and PHP runtime, so it can run anaywhere everywhere :D
